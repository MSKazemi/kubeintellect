# Licensing

## Current published notices

KubeIntellect source files and distributions carry GNU Affero General Public License (AGPL-3.0-or-later) notices. The current repository [LICENSE](LICENSE) contains the corresponding terms. These notices have not been replaced with MIT.

The existing AGPL permits research, teaching, modification, distribution, and commercial use under its conditions. No separate proprietary/commercial license is currently being offered through this repository.

## Rights under review

The University of Bologna has questioned the IP ownership and licensing authority for research-period work. The licensing position is subject to review. This repository notice does not decide ownership or grant new rights.

A future switch to MIT has been proposed, but **MIT is not currently in force**. See [draft pull request #248](https://github.com/MSKazemi/kubeintellect/pull/248). Any relicensing requires authorization from relevant rights holders and external contributors where necessary. Previously valid AGPL grants cannot be retroactively withdrawn.

## Research citation and contributions

Researchers are encouraged to cite the published work, described in [CITATION.cff](../CITATION.cff); this request does not add a license condition.

Contributors retain rights in their own contributions, which have been accepted under AGPL-3.0-or-later; see [CONTRIBUTING.md](../CONTRIBUTING.md).
