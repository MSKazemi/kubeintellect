# 09-install -- the no-cluster path: install the client, run the wizard, see what is configured.
#
# Format is `expect :: send`, driven by install_pty_driver.py. Unlike the eight diagnosis
# scenarios (which are prompts for the kq REPL), these are answers to `kubeintellect init`, a
# wizard built on plain input(). The driver matches the prompt text and fails non-zero if one
# never arrives -- a wizard that silently took a default for a question this file meant to answer
# is exactly the failure that still records a demo that looks fine.
#
# This sequence was verified end to end on 2026-08-28 against a pristine HOME: 6/6 prompts
# answered in order, driver exit 0. Re-verify after any change to cmd_init's prompts.
#
# RECORD IT LIKE THIS, and not any other way:
#   HOME=$(mktemp -d)   the wizard only offers to create a Kind cluster when ~/.kube/config is
#                       MISSING. On any machine that has ever touched a cluster it skips that
#                       branch entirely, so recording as yourself records a different wizard.
#   OPENAI_API_KEY=<throwaway>
#                       the key is echoed. `_mask` shows first-4 + last-4 (`sk-d***0000`), so a
#                       real key leaks 8 characters into the cast. Never record with a live key.
